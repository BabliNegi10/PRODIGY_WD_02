# ⏱️ Stopwatch Web Application

A modern and responsive stopwatch web application built using HTML, CSS, and JavaScript as part of my Prodigy InfoTech Web Development Internship.

## 🚀 Live Demo

https://bablinegi10.github.io/PRODIGY_WD_02/

## ✨ Features

- Start the stopwatch
- Pause the stopwatch
- Reset the stopwatch
- Record multiple lap times
- Modern glassmorphism UI
- Responsive design
- Smooth hover effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
